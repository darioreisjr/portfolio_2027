# Arquivos do autor

Pasta para os arquivos que acompanham o conteúdo: a foto e o currículo em PDF. Quem os coloca aqui é o autor.

Os arquivos desta pasta **ainda não são publicados**. Quando o primeiro chegar, falta ligá-lo à página: copiar para o `dist/`, definir o cache e apontar `profile.json` para o caminho. Avise ao colocar.

## Foto

| O quê   | Como                                                      |
| ------- | --------------------------------------------------------- |
| Onde    | `profile/dario-reis.jpg` (ou `.png`, `.webp`)             |
| Formato | Quadrada, 512×512 pixels ou maior, rosto centrado         |
| Junto   | Uma frase que descreva a foto, para o texto alternativo   |
| Aparece | Na ficha da área do recrutador, em 96×96, ao lado do nome |

## Currículo

| O quê   | Como                                                                          |
| ------- | ----------------------------------------------------------------------------- |
| Onde    | `cv/dario-reis-pt-br.pdf`, e, se houver, `cv/dario-reis-en.pdf` e `-es.pdf`   |
| Formato | PDF com texto selecionável, até 1 MB                                          |
| Cuidado | O arquivo fica público: só o que você quer que qualquer pessoa leia           |
| Aparece | No botão "Baixar currículo (PDF)" da área do recrutador, só no idioma que tem |

Sem arquivo, a página não mostra o retrato nem o botão.
